# OpenLexicon

An English-first bilingual legal lexicon drafted to support the study of legal English, with English definitions and Chinese term translations.

**[Read the dictionary → OpenLexicon.md](OpenLexicon.md)**

## Current edition

- **Version:** 1 · 2026-10-09
- **Entries:** 8,243 — 8,116 main entries and 127 abbreviations.
- **Format:** one Markdown file, grouped alphabetically, followed by an abbreviations section.

Each entry includes an English headword or phrase, an English explanation, and a Chinese translation. Separate senses, usage labels, Latin expressions, abbreviations, and cross-references are retained where present.

English definitions use the project's own wording. Chinese translations are working drafts pending editorial review; this edition does not claim comprehensive legal or translation verification.

## Reading and searching

Open [OpenLexicon.md](OpenLexicon.md), or download the file and read it in any Markdown or text editor. Search for an English headword or a Chinese term using the editor's search function.

## Repository scope

The current version contains only:

- `README.md` — this introduction.
- `OpenLexicon.md` — the complete core dictionary.

Development tools, split files, additional export formats, and automation are deferred. Earlier repository files remain available in Git history, but are not part of the current edition.
